Her Closet — small web To-Do example

This repository contains a simple client-side To-Do list application that uses the browser's localStorage for persistence.

Files:
- index.html — main UI
- styles.css — minimal styling
- main.js — application logic (add, edit, delete, mark complete, filter, clear completed)

How to use:
1. Clone or download the repository.
2. Open index.html in a modern browser (Chrome, Firefox, Edge, Safari).
3. Add tasks, edit them inline (click and type), toggle completion, and clear completed tasks.

Notes:
- Data is stored in localStorage under the key "her-closet-todo:v1". Clearing site data or using a different browser/device will not show the same tasks.
- This is purely client-side — no backend required.
